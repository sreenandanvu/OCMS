# OCMS — Online College Management System

A modern MERN-stack college management platform.

## First six modules
1. Admin & User Management
2. Student Management
3. Faculty Management
4. Attendance Management
5. Examination & Results
6. Reports & Analytics

## Stack
- MongoDB + Mongoose
- Express.js
- React + Vite
- Node.js
- JWT authentication
- Responsive CSS with Light / Dark / Auto theme

## Run locally

### Server
```bash
cd server
npm install
npm run dev
```

### Client
```bash
cd client
npm install
npm run dev
```

Set `server/.env` from `.env.example` before starting the API.
